# Статус лицензии

Лицензия проекта пока не выбрана владельцем. Этот файл не предоставляет
лицензию и не объявляет проект open source. Локальная сборка кандидата
не означает разрешения на внешнюю публикацию или распространение.
Перед releases/packages нужно отдельное решение владельца о лицензии,
адресе публикации и выпуске. Сторонний код в P16 не копировался.

Продукт использует стандартную библиотеку Go, без сторонних Go-модулей.
Правовые уведомления Go сохраняются в toolchain: $GOROOT/LICENSE и
$GOROOT/PATENTS; упаковщик добавляет их в архив как GO-LICENSE и GO-PATENTS.
Git не входит в архив и устанавливается пользователем отдельно.
